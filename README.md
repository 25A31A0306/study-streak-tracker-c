# Study Streak Tracker in C

A command-line application built in C to help users track their daily study streaks and monitor learning consistency.

## Features

* Record daily study sessions
* Track current study streak
* Track longest streak
* Reset streak when needed
* Simple menu-driven interface

## Concepts Used

* Functions
* Variables
* Loops
* Conditional Statements
* User Input Handling

## How to Run

Compile:

gcc streak.c -o streak

Run:

./streak

## Example

Current Streak: 5 days

Longest Streak: 12 days

## Project Purpose

This project was created to practice C programming fundamentals while building a simple productivity-focused application.
